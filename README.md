# Computer Vision — 표면 결함 검출 (Anomaly Detection)

OpenCV(C++)로 산업 표면 결함 검출을 직접 구현하며, **"파라미터를 조절하면 되겠지"라는 가설을 실험으로 반박하고 근본 원인을 찾아가는 과정**을 담은 저장소입니다. 산업 이상탐지 표준 데이터셋 **MVTec AD** 로 모든 결과를 실측했습니다.

> 딥러닝이 아닌 **고전 영상처리**로 파이프라인을 밑바닥부터 구현했습니다. 검사 알고리즘의 각 단계가 "무슨 문제를 푸는지"를 이해하고 직접 제어하는 것, 그리고 그 한계를 데이터로 규명하는 것이 목표였습니다.

## 핵심 서사 — 가설, 실험, 한계, 개선

```
1. CPU 베이스라인 구현
     정상 평균 → 차분 → 블러 → 이진화 → 모폴로지 → 연결요소
        │
2. "파라미터를 맞추면 되지 않을까?" — 실험으로 검증
     · threshold 스윕: 과검↔미검 시소, 균형점도 둘 다 35% 이상
     · min_area / blur 스윕: 과검이 34.8%에 고정 (안 줄어듦)
     → 결론: 단일 고정 파라미터로는 과검·미검 동시 개선 불가
        │
3. 원인 규명
     과검의 원인은 작은 노이즈가 아니라, 정상끼리도 변동이 큰
     "무늬 영역"이다. 픽셀마다 정상 변동(σ)이 다른데 같은 잣대를 씀.
        │
4. 적응형 임계값(k·σ)으로 극복
     픽셀별 σ를 학습 → "정상 변동 대비 몇 σ 벗어났나"로 판정
     → 같은 미검 수준에서 과검 최대 ~22%p 감소
        │
5. 남은 한계 → 다음 방향
     과검 34.8%는 σ로도 안 걸러짐 = 무늬가 아닌 정렬·조명 문제
     → registration(정합), 그리고 촬영 조건 통제(광학)
```

**측정 지표**: 과검(정상을 결함이라 함) / 미검(결함을 놓침) — 폴더별로 집계.
모든 실험의 원본 수치는 각 프로젝트의 `experiments/` CSV에 있습니다.

## 결과 요약

MVTec AD capsule · 정상 219장 학습 → test 132장(정상 23 / 결함 109) · Intel i5-6600, MSVC Release x64.

| | 과검 (정상 오검) | 미검 (결함 놓침) | 처리시간 |
|---|---:|---:|---:|
| v1 고정 임계값 (best 균형) | 34.8 % | 37.6 % | ~7.5 ms |
| **v2 적응형** (미검 맞춤) | **65.2 %→ 개선폭 −22 %p** | 6.4 % | ~23 ms |

> 이 수치들은 실용 검사기 수준은 아닙니다(그러려면 정렬·조명 통제와 학습 기반 방법이 필요). **이 저장소의 목적은 "완성된 검사기"가 아니라, 고전 방법의 한계를 직접 실험해 규명하고 개선 방향을 도출하는 과정**입니다.
