# 표면 결함 검출 — 적응형 임계값 (v2)

[v1 (CPU baseline)](../AnomalyDetection-cpu-baseline) 의 후속. v1은 모든 픽셀에 **같은 고정 임계값**을 썼지만, 실험 결과 어떤 고정 파라미터로도 과검·미검을 동시에 낮추지 못했습니다. v2는 **픽셀마다 다른 임계값**을 적용해 이 한계를 넘습니다.

---

## 왜 적응형인가

정상 제품이라도 픽셀 위치에 따라 "정상일 때의 변동 폭"이 다릅니다.

- **매끈한 영역** — 정상끼리 거의 안 변함(σ 작음) → 조금만 달라도 이상
- **무늬·인쇄 영역** — 정상끼리도 들쭉날쭉(σ 큼) → 좀 달라도 정상

고정 임계값 하나로는 둘을 함께 만족시킬 수 없습니다(v1 실험 A/B/C에서 과검이 34.8 % 벽에 막힘). 그래서 픽셀마다 **정상 표준편차 σ** 를 학습해두고, "절대 밝기차"가 아니라 **"정상 변동 대비 몇 σ 벗어났는가"** 로 판정합니다.

---

## 방식

**train — 픽셀별 평균과 표준편차**

정상 이미지들에서 합(Σx)과 제곱합(Σx²)을 함께 누적해, 한 번의 순회로 평균과 표준편차 맵을 만듭니다.

```
σ² = E[X²] − (E[X])²        (제곱의 평균 − 평균의 제곱)
```

**detect — k·σ 판정**

```
score(x, y) = |입력 − 평균| / max(σ, sigma_min)
결함 ⟺ score > k
```

- σ가 큰 무늬 영역은 score가 작아져 **자동으로 관대**해지고, σ가 작은 매끈한 영역은 **엄격**해집니다.
- `k` — 임계 배수(정규분포 3σ 관례). `sigma_min` — σ 바닥값(정상끼리 거의 안 변하는 픽셀의 0-나눗셈·과민 방지).

이후 blur → 이진화(score > k) → 모폴로지 → 연결요소는 v1과 동일합니다.

## 결과 — v1 대비

MVTec AD capsule, 정상 219장 학습 → test 132장(정상 23 / 결함 109). i5-6600, Release x64.

**실험 D — k 스윕** ([`experiments/exp_D_k_sweep.csv`](experiments/exp_D_k_sweep.csv))

| k | 과검 | 미검 |
|---:|---:|---:|
| 2.5 | 82.6 % | 1.8 % |
| 3.0 | 69.6 % | 3.7 % |
| 3.5 | 65.2 % | 6.4 % |
| 4.0 | 56.5 % | 12.8 % |
| 4.5 | 43.5 % | 22.0 % |
| 5.0 | 34.8 % | 32.1 % |

**같은 미검 수준에서 과검이 낮습니다** — 적응형의 효과:

| 미검 ≈ | v1 고정 과검 | v2 적응형 과검 | 개선 |
|---|---:|---:|---:|
| ~2 % | 91.3 % (t=30) | 82.6 % (k=2.5) | −8.7 %p |
| ~5 % | 87.0 % (t=35) | **65.2 % (k=3.5)** | **−21.8 %p** |
| ~13–21 % | 69.6 % (t=40) | 56.5 % (k=4.0) | 과검·미검 모두 개선 |

### 남은 한계 (정직한 메모)

k를 5 이상 올리면 과검이 다시 **34.8 %에 고정**됩니다 — v1에서 본 것과 같은 벽입니다. 적응형으로 **무늬가 만든 과검은 상당수 제거했지만**, 남은 34.8 %(정상 23장 중 8장)는 σ로도 안 걸러집니다. 이는 무늬가 아니라 **입력–기준의 정렬 오차·조명 차이**가 원인이라는 신호이며, 다음 개선은 **정합(registration)** 입니다.

### 비용

| | v1 고정 | v2 적응형 |
|---|---:|---:|
| 처리시간 mean | ~7.5 ms | ~23 ms |
| 처리량 | ~130 FPS | ~45 FPS |

픽셀별 σ 나눗셈(float)이 추가돼 약 3배 느립니다. **정확도를 위해 속도를 지불한** 명확한 트레이드오프입니다.

## 빌드 · 실행

v1과 동일(VS 2022, vcpkg OpenCV x64, Release). 인자만 다릅니다.

```
AnomalyDetection-adaptive.exe <capsule_root> [k] [sigma_min] [min_area] [blur_ksize] [morph_ksize]
  기본값: k=3.0  sigma_min=3.0  min_area=50  blur_ksize=5  morph_ksize=5
```

데이터셋(MVTec AD)은 [v1 README](../AnomalyDetection-cpu-baseline/README.md#데이터셋) 참고 — 저장소에 포함하지 않습니다.
